BLACKJACK TRAINER — v6.6.1 WEB EDITION

SUBIR DIRECTAMENTE A VERCEL

Opción recomendada:
1. Descomprime este ZIP.
2. En Vercel selecciona Add New > Project.
3. Elige la opción para importar/subir el proyecto.
4. Sube todos los archivos que están en la raíz de esta carpeta.
5. Framework Preset: Other.
6. Build Command: dejar vacío.
7. Output Directory: dejar vacío.
8. Pulsa Deploy.

ARCHIVOS WEB
- index.html: aplicación principal.
- vercel.json: configuración automática de Vercel.
- manifest.webmanifest: instalación como aplicación web.
- service-worker.js: caché básica para uso sin conexión.
- icon-192.png / icon-512.png / favicon.ico: iconos.

IMPORTANTE
Esta versión todavía guarda los datos en el navegador mediante almacenamiento local.
Los datos no se sincronizan entre teléfonos o computadoras.
La futura v7.0 incorporará cuentas de usuario y base de datos en Supabase.
